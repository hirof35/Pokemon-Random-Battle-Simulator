Pokemon Random Battle Simulator (C-Language)
C言語の構造体とポインタを活用した、コマンドライン・ターン制バトルシミュレーターです。
ランダムに選出された2体のポケモンが、力尽きるまで自動で戦います。

🚀 特徴
ポインタによるデータ管理: ポインタ（PokemonPtr）を使用して、配列内のデータに対して効率的にアクセス・更新を行います。

多ファイル構成: ヘッダーファイルによるインターフェース設計と、実装ファイルを分けたメンテナンス性の高いコード構造。

動的シミュレーション: rand() を用いた先攻・後攻の決定および対戦相手の選出。

ターン制 UI: ユーザーの入力（Enterキー）を待機しながら1ターンずつ進行する、インタラクティブな実行画面。

📋 セットアップ・ビルド
構成ファイル
pokemon_game.h: 構造体の定義と関数宣言

functions.c: バトルロジックとマスターデータの実装

main.c: エントリポイント（ゲームの開始）

コンパイル例
Bash
gcc main.c functions.c -o pokemon_battle
実行
Bash
./pokemon_battle
🎮 遊び方
プログラムを起動すると、全10種類のポケモンの中から2体がランダムに選ばれます。

どちらが先制するかランダムに決定されます。

[Enter] キーを押すたびに攻撃が行われ、ダメージと残りHPが表示されます。

どちらかのHPが0になるとバトル終了です。

📐 設計思想：ポインタと実体
本プログラムでは、Pokemon 構造体の実体（pokemon_data 配列）を一つの場所で管理し、関数間ではそのアドレス（ポインタ）のみをやり取りしています。これにより、大規模なデータを扱う際にもメモリ消費を抑え、高速なデータアクセスを実現する「実戦的なC言語プログラミング」の基礎を体現しています。

🛠 今後の拡張予定（思想工学的アプローチ）
タイプ相性の実装: enum を用いた属性定義とダメージ倍率計算。

技の選択: 構造体内に「技」の配列を持たせ、威力の異なる攻撃を可能にする。

永続化: 対戦成績をファイルに保存する機能の追加。
